# 内容方案：把"很多内容"做成护城河而不是负债

> 实测依据：一家只有 **81** 个 URL，另一家有 **4,115** 个（12 个子 sitemap：黄历日 1210、奇门 675、
> 紫微 470、塔罗 395、64 卦 320、神煞 285、guides 240、格局 120…），并且**明确放开了对 AI 爬虫的封锁**
> 以换取被 ChatGPT/Claude 引用的机会。结论：**内容量不是副产品，是流量入口本身**。
> 但"多"必须建立在**一个原语一页**的规则上，否则就是一堆互相重复、也骗不过搜索引擎的页面。

配套：[PLAN.md](PLAN.md) §5（成本）、[PROTOCOL.md](PROTOCOL.md)（内核事实是内容的事实来源）。

---

## 1. 核心规则

1. **一个领域原语 = 一个页面。** 不是"一篇文章讲神煞"，而是"一页讲某一个神煞"。
2. **页面的数据必须来自内核**，模型只解释、不计算（同 I1/I2 不变量）。这样 4,000 页的内容与产品结论**天然一致**，
   也避免了同一术语在不同页面各说各话。
3. **内容必须能被机器引用。** 结构化数据 + 稳定 URL + 清晰定义段，是 AI 搜索引擎愿意引用的前提。
4. **多语言是乘法，不是加法。** 先做扎实一种，再按 ×N 摊开；语言集建议对齐两家的并集
   （zh-CN / zh-TW / en / ja / ko / vi / de / ru）。

## 3. 页型模板（固定骨架，不要每页自由发挥）

```markdown
# {原语名}（{拼音/英文}）

> 一句话定义：{40 字以内，必须能被单独引用}

## 它是什么
{定义 + 出处（古籍卷次为公有领域；现代资料只作参考不照抄）}

## 怎么算出来
{来自内核的确定性规则，逐步列出；展示一个可复算的示例}

## 落在命盘上会怎样
{结构化的影响表：与其他原语的常见组合 → 表现}

## 实务上怎么用
{3–5 条可执行建议；语气克制，不做吉凶断言式恐吓}

## 常见误解
{2–3 条，用来抵消同类站点的错误说法——这是差异化来源}

## 相关
{内链到 5–8 个相邻原语 + 1 个工具页}

## FAQ
{3 条问答，直接回答搜索意图}
```

**每页必带的机器可读部分**：`FAQPage` / `Article` 结构化数据、`canonical`、`hreflang` 全语言互链、
末次更新时间，以及**内核版本号**（内容与算法版本绑定，见 §6）。

## 4. 生成管线（关键：让"批量"不变成"垃圾"）

```
原语清单(受控词表)
  → 内核产出结构化事实(kernel facts)
  → 模板渲染骨架(标题/小标题/表格结构固定)
  → LLM 只做"把事实讲成人话"(受限叙述层)
  → 规则校验器(硬门禁)
  → 人工抽检(按比例 + 必检高风险词)
  → 发布(带内核版本与更新时间)
  → 定期重生成(内核升级 / 事实变更)
```

**规则校验器的硬门禁（不过就不许发）**
1. 出现受控词表之外的术语 → 拒；
2. 出现内核 facts 之外的数字/干支/日期 → 拒（这一条直接挡住幻觉）；
3. 断言式预测（"你一定会…"）或医疗/投资/法律建议 → 拒；
4. 与相邻页面的定义段重复度过高 → 拒（重复内容会被合并或降权）；
5. 缺 FAQ / 结构化数据 / 内链 → 拒。

**成本控制**：长尾页用**小模型 + 严格模板**（每页 1–2k token 量级），只有"旗舰工具页"才用大模型精写；
滚动页（黄历）完全由内核生成，不调用模型。缓存键 = `hash(facts) + template_version + locale`。

## 5. SEO / GEO 动作清单

- [ ] 每原语一页 + 全语言互链（`hreflang` 完整，与两家里 8 语言的做法一致）
- [ ] 站点地图**按原语分片**（不要一个巨型 sitemap.xml），并在 robots.txt 里声明
- [ ] **放行 AI 爬虫**（GPTBot / ClaudeBot / PerplexityBot 等），并把它写进 robots.txt 注释便于后人别改回去
- [ ] 归因里把 AI 助手来源单列（chatgpt / claude / perplexity / poe…）——**度量了才会继续投入**
- [ ] 结构化数据：Article/FAQPage/HowTo；定义段用 `<dfn>` 或明确的"是什么"标题
- [ ] 内链矩阵：每个原语链到 5–8 个相邻原语，形成稠密图而不是星形
- [ ] 工具页与内容页互链：内容页导流到免费工具，工具结果页导流回相关原语

## 6. 版本与重生成策略

内容与内核必须**同源同版**：

| 变化 | 动作 |
|---|---|
| 内核算法变更（如子时口径） | 标记 `kernel_version`，重生成**受影响的**页面（按 facts 差异筛选），加更新说明 |
| 模板改版 | 全量重渲染，`template_version` +1 |
| 古籍依据补充 | 只更新"出处"段，不动结论 |

> 这条能避免最尴尬的事故：用户三个月前看过的页面，与今天算出来的结果自相矛盾。

---

## 7. 合规与语气

- 全站免责：**文化娱乐内容，不构成医疗、投资、法律或心理建议**；不承诺准确性。
- 不做恐吓式转化（"不化解会有灾"这类必须禁止）；不做付费后才告知"凶"的机制。
- 生辰相关的一切内容**不进入公开页面**（生成的是通用知识页，不是用户命盘）。
- 内容审核分级：通用知识页自动过门禁；涉及健康/婚姻/财务建议的段落走人工。

AI 爬虫放行且来源桶有数据。
